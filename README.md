# NB Termometria

Site institucional da **NB Termometria / Nied e Cia**, desenvolvido como projeto da disciplina de **Desenvolvimento de Aplicações I**, na avaliação Nota 3: *Desenvolvimento de Interfaces web interativas*.

> **Aviso:** este é um projeto acadêmico, feito por estudantes com autorização da empresa. **Não é o site oficial.** O site oficial da empresa está em [nbtermometria.com.br](https://nbtermometria.com.br/).

## Site no ar

**https://nb-termometria.pages.dev/**

## Tecnologias

- HTML5
- CSS3
- JavaScript

O projeto usa **somente essas tecnologias**, sem frameworks, bibliotecas ou CDNs, conforme exigido no enunciado da disciplina.

## Hospedagem e publicação

O site é hospedado no **Cloudflare Pages**, conectado a este repositório:

- Cada alteração que entra na `main` é publicada automaticamente.
- Cada Pull Request gera um **link de prévia** do site para teste antes do merge.

## Estrutura do repositório

```text
.
├── .github/
│   └── PULL_REQUEST_TEMPLATE.md   # Modelo de descrição dos Pull Requests

├── CONTRIBUTING.md                # Fluxo de trabalho da equipe
├── README.md                      # Este arquivo
└── index.html                     # Página inicial
```
